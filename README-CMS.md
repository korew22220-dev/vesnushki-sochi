# Редактирование сайта «Веснушки»

Используется **прежняя собственная админ-панель Sites**, перенесённая в `admin/`.
Интерфейс находится по `/admin/`; источник контента — `content/site.json`.
Генератор `render_site.py` формирует сайт и админку в `dist/`.

Настройка владельцем, учётные записи, работа клиента и восстановление:
[README-ADMIN.md](README-ADMIN.md).

**Статус:** интеграция подготовлена в рабочей ветке. Пока `admin/config.js`
не содержит URL развёрнутого API, вход и сохранение недоступны.
Полный цикл с настоящими аккаунтами и публикацией ещё не проверен.

Pages CMS больше не используется. Предыдущая конфигурация сохранена в
`docs/pages-cms-legacy.yml` для истории; она описывает старую схему и не
подходит для новых данных. Данные мигрированы в схему `schemaVersion: 2`,
соответствующую собственному редактору. Второго хранилища контента нет.
