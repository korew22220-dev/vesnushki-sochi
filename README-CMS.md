# Редактирование сайта «Веснушки»

Сайт размещён на GitHub Pages. Pages CMS редактирует `content/site.json`
и загружает фотографии в `media/`. Скрипт `render_site.py` собирает
готовую страницу из `site-template.html`; опубликованную страницу вручную
редактировать не нужно.

## Первое подключение

1. В репозитории GitHub откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
2. Дождитесь успешного запуска **Actions → Publish Веснушки**. Проверьте, что домен `vesnushki-sochi23.ru` остался в настройках Pages и включён HTTPS.
3. Откройте [app.pagescms.org](https://app.pagescms.org/), войдите через GitHub и установите Pages CMS GitHub App с доступом к этому репозиторию.
4. Откройте репозиторий в Pages CMS: файл `.pages.yml` уже настроен.
5. В Pages CMS пригласите клиента по электронной почте в качестве collaborator.

После сохранения текста или загрузки фото Pages CMS создаёт коммит в GitHub.
Workflow собирает статический HTML и публикует новую версию. Обычно это
занимает несколько минут. Для проверки локально: `python3 render_site.py`.

Поля в редакторе меняют текст, контакты, цены и выбранные фотографии.
Формы Яндекса, оформление и интерактивность сайта остаются в исходном коде.
Если меняется адрес, SEO метаданные, карта и ссылки маршрута требуют
отдельной правки в `site-template.html`.
