# Веснушки — детский сад в Сочи

Открытая версия сайта для показа клиенту. Фотографии и видео предоставлены заказчиком. Публикация — GitHub Pages, ветка main, корень репозитория.

В этой версии нет админки и серверной статистики. Редактирование контента остаётся в основной версии Sites. После изменений в админке копию GitHub нужно обновить отдельно. Приём заявок через форму не подключён; запись доступна по телефону.
