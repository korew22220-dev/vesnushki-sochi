# Веснушки — детский сад в Сочи

Сайт: https://vesnushki-sochi23.ru/

Статический сайт на GitHub Pages. Собственная админ-панель перенесена из
существующего проекта Sites в `admin/`. Она редактирует `content/site.json`
через серверный API, затем GitHub Actions запускает `render_site.py`.
Готовый сайт и панель собираются в `dist/`.

Настройка авторизации, API, клиента и проверка публикации:
[README-ADMIN.md](README-ADMIN.md). Вход и запись станут доступны только
после настройки внешних сервисов; полный реальный цикл ещё не проверен.
Форма записи подключена через Яндекс Формы.
