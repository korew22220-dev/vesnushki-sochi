# Веснушки — детский сад в Сочи

Сайт: https://vesnushki-sochi23.ru/

Статическая публикация на GitHub Pages. Контент для редактора Pages CMS хранится в `content/site.json`, конфигурация — в `.pages.yml`. Сборка выполняется GitHub Actions из `site-template.html` с помощью `render_site.py`.

Первоначальные действия владельца GitHub и порядок приглашения клиента описаны в [README-CMS.md](README-CMS.md). Форма записи подключена через Яндекс Формы.
